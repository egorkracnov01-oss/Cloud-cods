# Вкладка «Подписка»

Страница подписки на ежемесячный подарочный набор с продукцией. Три уровня: **Лёгкая**, **Средняя** и **Высокая**.

## Состав

- `index.html` — страница: первый экран, «Как это работает», три тарифа, переключатель срока (1/3/6/12 мес. со скидкой), FAQ, форма заявки.
- `css/subscription.css` — стили (цвета задаются переменными в `:root`).
- `js/subscription.js` — пересчёт цен, модальное окно, отправка заявки.

## Как встроить в сайт

1. Скопируйте папку `subscription/` на сервер, чтобы страница открывалась по адресу `/subscription/`.
2. В общее меню сайта добавьте пункт:
   ```html
   <a href="/subscription/">Подписка</a>
   ```
3. Замените в `index.html` временную шапку и подвал на общие шапку и подвал сайта.
   Если сайт работает на CMS (WordPress, Tilda, 1С-Битрикс), перенесите содержимое `<main>` и `<dialog>` на новую страницу, а CSS и JS подключите к ней.

## Что настроить

- **Цены**: атрибут `data-base` у `.price-value` в `index.html` (сейчас 990 / 1 990 / 3 490 ₽ в месяц, это примерные цены).
- **Скидки за срок**: объект `DISCOUNTS` в `js/subscription.js`.
- **Состав наборов**: списки `.features` в `index.html`.
- **Приём заявок**: в `js/subscription.js` впишите в `ENDPOINT` адрес обработчика на сервере (например, отправка на почту или в CRM). Заявка уходит POST-запросом в формате JSON:
  `{ tier, months, name, phone, email, address, agree, total }`.
  Пока `ENDPOINT` пустой, заявка только выводится в консоль браузера.
